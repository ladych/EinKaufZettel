# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting instead:
**Security → Report a vulnerability** in this repository. You will get an answer within a few days.

EinKaufZettel works offline, has no account system and no network access, so the attack surface is small.
Reports about data leaks through backups, exported files or third-party recognition services are still
very welcome.

## Supported versions

Only the latest release receives fixes.
